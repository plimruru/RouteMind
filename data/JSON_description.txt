requests.json
Синтетический набор заявок для работы алгоритма планирования.
Файл сформирован путём объединения синтетических данных по трём регионам: Югоцентр, Юго-восток и Восток. Всего набор содержит 205 заявок.
Для каждой заявки сохранены идентификатор, регион, район, адрес, временное окно, типы заявки BK и HD. На основании типа BK заявке присваивается один из трёх основных навыков (required_skill), соответствующих справочнику задания. Тип HD используется как более подробная специализация (required_specialization).
В данные синтетически добавлено ограничение по транспорту (required_transport). У большей части заявок конкретный транспорт не требуется; для остальных вид транспорта генерируется в зависимости от типа заявки.

brigades.json
Справочник бригад, сформированный на основе контрольного распределения.
Файл содержит 35 бригад из трёх регионов. Для каждой бригады создан уникальный идентификатор вида регион + название бригады, что позволяет различать одинаковые названия бригад в разных регионах.
Навыки (skills) и специализации (specializations) восстанавливаются по типам заявок, которые были назначены бригаде в контрольном распределении. home_district определяется как район, в котором бригада чаще всего получала заявки, а served_districts содержит все районы, встречавшиеся в её истории назначений.
Стартовая точка соответствует офису региона. Вид транспорта бригады сформирован синтетически.

control_distribution.json
Контрольное распределение заявок между бригадами.
Файл содержит исходные назначения заявок конкретным бригадам и используется не как вход оптимизатора, а для анализа исходного распределения, восстановления характеристик бригад и последующего сравнения с результатом разработанного алгоритма.
Для каждой записи сохраняются заявка, её тип, статус, временное окно, адрес, район, назначенная бригада, регион, стартовая точка и определённые на этапе обработки skill и specialization.
