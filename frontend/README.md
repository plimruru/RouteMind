# RouteMind frontend

## Запуск

Откройте Terminal и выполните:

```bash
cd "/Users/lisa_kar/Desktop/Хакатон мос/RouteMind"
python3 frontend/server.py
```

После строки `RouteMind: http://127.0.0.1:8000` откройте в браузере:

http://127.0.0.1:8000

Для остановки сервера нажмите `Control + C` в Terminal.

При первом нажатии «Создать маршруты» сервер автоматически соберёт локальную копию C++-планировщика. Это может занять несколько секунд.

## Если автоматическая сборка не запустилась

Из корня RouteMind выполните один раз:

```bash
cmake -S . -B build
```

Затем снова запустите:

```bash
python3 frontend/server.py
```

## Проверка функционала

1. Дата должна быть `17.08.2026` — на неё подготовлены исходные заявки.
2. Нажмите «Выгрузить заявки».
3. Нажмите «Создать маршруты» и дождитесь результата C++.
4. Переключайте бригады над картой и выбирайте заявки слева.
5. Нажмите «Новая заявка», заполните форму и затем повторно постройте маршруты.

Новые заявки сохраняются только в `frontend/user_requests.json`. Исходные файлы в `data/` и код C++ не изменяются.
